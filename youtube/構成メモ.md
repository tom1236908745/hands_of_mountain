## 2. ことばの選び方（いちばん大事）

**「聞いたことはある」×「意味はあやふや・知らない」** のことばを選ぶ。

| | 意味を知っている | 意味はあやふや・知らない |
|---|---|---|
| **聞いたことがある** | × 新しい発見がない（例：笑う門には福来たる） | ◎ **ここを狙う** |
| **聞いたことがない** | ― | × 興味を持たれにくい（例：和顔愛語） |

さらに強いのは、次のどれかがあることば：
- **誤解されがち**：本当の意味が、思われているのと違う（例：情けは人の為ならず、他力本願、狭き門）
- **由来が意外**：ふだん使うことばが、実は仏教・聖書から（例：挨拶、我慢、目から鱗、豚に真珠）
- **心が軽くなる**：意味を知ると、気持ちが少し楽になる（例：塞翁が馬、一隅を照らす）

迷ったら、身近な人に「〇〇ってどういう意味？」と聞いて、**すぐ答えられなければ合格**。

## 3. シリーズ（カテゴリ）

偏らないように順番に回す（仏教 → 故事 → 聖書 → 故事 …）。

| シリーズ | 例（2.の基準に合うもの） |
|---|---|
| 仏教のことば | 一隅を照らす、諸行無常、他力本願、挨拶、我慢、玄関、一期一会 |
| 聖書のことば | 目から鱗、狭き門、豚に真珠、地の塩、求めよさらば与えられん |
| 故事・ことわざ | 塞翁が馬、雨垂れ石を穿つ、情けは人の為ならず、杞憂、蛇足、覆水盆に返らず |
| 世界の古ことば | 論語（温故知新・過ぎたるは猶及ばざるが如し）、イソップ（すっぱいぶどう） |

## 4. 1本の型（ショートアニメ 35〜38秒・縦）

制作仕様の書式は `anime/SPEC_TEMPLATE.md`、完成例は `anime/episodes/ep01_ichigu/spec.md`。

| 場面 | 目安 | 役割 | カメラ |
|---|---|---|---|
| 起 | 0–6秒 | 主人公と「願い」。**最初の2秒で絵として目を引く**（群れが舞う・光る など） | 引き |
| 承 | 6–12秒 | 主人公が自分のためにがんばるが、うまくいかない | 顔に寄る |
| 転 | 12–20秒 | 目の前の誰か・何かに気づく。願いが変わる | 少し引く |
| 山場 | 20–24秒 | 変化が起きる瞬間（光る・咲く・届く）。音楽も一番ふくらむ | 引いて状況を見せる |
| 結 | 24–34秒 | 結果 →「ことば」を明朝体で大きく＋出典 | 大きく引く |
| 余韻 | 34–38秒 | 本来の意味を3行で。黒にフェード | 引きのまま |

ルール
- **セリフなし**。字幕は1行15字前後、画面上から1/3の位置（下はアプリのUIで隠れる）
- 「ことば」は**結**で初めて出す（物語を見たあとに意味がつながる気持ちよさ）
- 「自分のため → だれかのため」のような**対比**で、ことばの核を見せる
- 諸説ある解釈は spec の「解釈上の注意」に書き、否定的・断定的な表現を避ける

## 5. タイトル・カバー

- ショートでは**タイトルしか読まれない**。前半に「続きが気になる一文」、後ろにハッシュタグ
- タイトル：`物語の気になる一文…🐾 #ことば #シリーズ #ショートアニメ`
  （例：`光れないほたるが、ある子のために願ったら…🐾 #一隅を照らす #最澄 #ショートアニメ`）
- 固定コメント：「あなたの“〇〇”はどこですか？🐾」のような問いかけを最初に書く
- カバー画像：山場の一番きれいなコマ（`meta.yaml` の `cover_time`）
- 説明文：ことばの意味2行＋出典＋諸説の注記＋ハッシュタグ（`meta.yaml` → `post.txt`）

## 6. 投稿ペース

**ゆるく続ける**（無理のないペースで。止めないことを優先）。

| 段階 | 目安 |
|---|---|
| はじめ | できたものから投稿。同じことば（ep02/ep03）は間をあける。YouTubeショート・TikTok・リールに同じ動画を投稿 |
| 10本たまったら | 反応のよかった主人公で「続編」・シリーズ化 |
| 登録者が増えたら | 人気の主人公でLINEスタンプ → 概要欄で告知 |

## 付録：解説動画の型（必要なときだけ）

マスコット「ことにゃん」が字幕で解説する形式（`episodes/*.yaml` → `tools/render.py`）。
title → quote（原文）→ talk（意味）→ talk（由来）→ talk（誤解・今の使い方）→ ending。各シーン10秒以上。
