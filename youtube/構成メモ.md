# 構成メモ — ことにゃんの古ことば帖

チャンネルの方針・1本の動画の型・ネタ帳をまとめたメモ。
**動画を作る前にここを見て、作ったらネタ帳を更新する。**

---

## 1. チャンネルの軸

| 項目 | 内容 |
|---|---|
| チャンネル名 | ことにゃんの古ことば帖 |
| ひとことで | 仏教・聖書・故事成語の「古いことば」を、**セリフなしの小さな物語アニメ**で伝える |
| 見てほしい人 | 疲れたときにやさしい話を見たい人、名言・ことわざが好きな人、海外の視聴者（セリフなしなので伝わりやすい） |
| 見たあとの気持ち | 「じんわりした」＋「ことばの本当の意味を知った」 |
| 他との違い | 解説ではなく**物語で体験させる**。出典つき・教えの押しつけなし・絵本のようなやさしい絵 |
| 収益の柱 | ① YouTube広告（ショート→長尺への導線）② LINEスタンプ ③ グッズ |

## 2. シリーズ（カテゴリ）

偏らないように順番に回す（仏教 → 故事 → 聖書 → 故事 …）。

| シリーズ | 例 |
|---|---|
| 仏教のことば | 一隅を照らす、諸行無常、一期一会、和顔愛語、自灯明 |
| 聖書のことば | 一粒の麦、狭き門、汝の隣人を愛せ、目から鱗、地の塩 |
| 故事・ことわざ | 塞翁が馬、雨垂れ石を穿つ、蛍雪の功、井の中の蛙、愚公山を移す |
| 世界の古ことば | 論語、イソップ、ギリシャ神話由来のことば |

## 3. 1本の型（ショートアニメ 30〜45秒・縦）

制作仕様の書式は `anime/SPEC_TEMPLATE.md`、完成例は `anime/episodes/ep01_ichigu/spec.md`。

| 場面 | 目安 | 役割 | カメラ |
|---|---|---|---|
| 起 | 0–6秒 | 主人公と「願い」。**最初の2秒で絵として目を引く**（群れが舞う・光る など） | 引き |
| 承 | 6–12秒 | 主人公が自分のためにがんばるが、うまくいかない | 顔に寄る |
| 転 | 12–20秒 | 目の前の誰か・何かに気づく。願いが変わる | 少し引く |
| 山場 | 20–24秒 | 変化が起きる瞬間（光る・咲く・届く）。音楽も一番ふくらむ | 引いて状況を見せる |
| 結 | 24–34秒 | 結果 →「ことば」を明朝体で大きく＋出典 | 大きく引く |
| 余韻 | 34–38秒 | 本来の意味を3行で。黒にフェード | 引きのまま |

ルール
- **セリフなし**。字幕は1行15字前後、画面上から1/3の位置（下はアプリのUIで隠れる）
- 「ことば」は**結**で初めて出す（物語を見たあとに意味がつながる気持ちよさ）
- 「自分のため → だれかのため」のような**対比**で、ことばの核を見せる
- 諸説ある解釈は spec の「解釈上の注意」に書き、否定的・断定的な表現を避ける

## 4. タイトル・カバー

- タイトル：`物語の一言 ｜ ことば #shorts`（例：`光れなかったホタルの話 ｜ 一隅を照らす #shorts`）
- カバー画像：山場の一番きれいなコマ（`meta.yaml` の `cover_time`）
- 説明文：ことばの意味2行＋出典＋諸説の注記＋ハッシュタグ（`meta.yaml` → `post.txt`）

## 5. 投稿ペース

| 段階 | 目安 |
|---|---|
| 最初の1か月 | 週2本（YouTubeショート・TikTok・リールに同じ動画を投稿） |
| 10本たまったら | 反応のよかった主人公で「続編」・シリーズ化 |
| 登録者が増えたら | 人気の主人公でLINEスタンプ → 概要欄で告知 |

## 付録：解説動画の型（必要なときだけ）

マスコット「ことにゃん」が字幕で解説する形式（`episodes/*.yaml` → `tools/render.py`）。
title → quote（原文）→ talk（意味）→ talk（由来）→ talk（誤解・今の使い方）→ ending。各シーン10秒以上。
