# 構成メモ — ことにゃんの古ことば帖

チャンネルの方針・1本の動画の型・ネタ帳をまとめたメモ。
**動画を作る前にここを見て、作ったらネタ帳を更新する。**

---

## 1. チャンネルの軸

| 項目 | 内容 |
|---|---|
| チャンネル名 | ことにゃんの古ことば帖 |
| ひとことで | 三毛猫ことにゃんが、仏教・聖書・故事成語の「古いことば」をやさしく1〜2分で紹介 |
| 見てほしい人 | 雑学好きの大人、ことわざ・語源が気になる学生、癒やし目当てで猫が好きな人 |
| 見たあとの気持ち | 「へえ、知らなかった」＋「ちょっと前向きになれた」 |
| 他との違い | 宗教の**ことば**を、教えの押しつけなしに、出典つきで、かわいく |
| 収益の柱 | ① YouTube広告 → ② LINEスタンプ → ③ グッズ（ステッカー・アクスタ・手ぬぐい） |

## 2. シリーズ（カテゴリ）

`config.yaml` の `categories` と対応。偏らないように順番に回す。

| category | シリーズ名 | 色 | 例 |
|---|---|---|---|
| `buddhism` | 仏教のことば | 茶 | 諸行無常、他力本願、我慢、挨拶、玄関 |
| `christian` | 聖書のことば | 青 | 目から鱗、狭き門、豚に真珠、汝の敵を愛せよ |
| `kotowaza` | 故事・ことわざ | 緑 | 塞翁が馬、蛇足、矛盾、四面楚歌、漁夫の利 |
| `other` | 世界の古ことば | 紫 | ギリシャ神話由来の語、論語、ことわざの世界比較 |

**ローテーション例**：仏教 → 故事 → 聖書 → 故事 → 仏教 → その他 …（故事は伸びやすいので多め）

## 3. 1本の動画の型（横動画 1〜2分）

| # | type | 時間の目安 | 内容 | 表情 |
|---|---|---|---|---|
| 1 | `title` | 〜10秒 | あいさつ＋今日のことば。**最初の5秒で「えっ？」と思わせる** | happy → wink |
| 2 | `quote` | 10〜15秒 | 原文と出典（ある場合） | normal |
| 3 | `talk` | 15〜20秒 | 本来の意味 | normal / thinking |
| 4 | `talk` | 20〜40秒 | 由来・物語（故事は①②③と分割） | surprised / sad |
| 5 | `talk` | 15〜20秒 | よくある誤解 or 今の使い方 | thinking / wink |
| 6 | `ending` | 〜10秒 | ひとことまとめ＋締め台詞 | satori → happy |

- 1シーン3行前後、**各シーン10秒以上**（YouTubeのチャプター条件）
- 合計 20〜30 行
- 「意外性」をどこかに1つ入れる（例：諸行無常は実は希望のことば／我慢は元々悪い意味）

### ショート（縦 1分以内）

- 横動画と同じ台本から `--format shorts` で作る
- 長いときは物語シーンに `shorts: false` を付けて削る
- 最初の1行で結論か疑問を言い切る

## 4. タイトル・サムネの型

- タイトル：`【シリーズ名】「ことば」＋意外性のある問い`
  - 例：`【仏教】「我慢」は元々悪い意味だった？`
- サムネのキャッチ（`thumbnail.catch`）：2〜3行・各6〜8字、問いかけ or 驚き
- サムネの表情：`surprised` / `thinking` が強い。`satori` はまとめ回向け

## 5. 投稿ペース

| 段階 | 目安 |
|---|---|
| 最初の1か月 | 横 週2本＋ショート 週3本（台本は1本で両方つくれる） |
| 30本たまったら | 再生の多いシリーズを増やす。人気回の「続編」を作る |
| 登録者が増えてきたら | LINEスタンプ第1弾を申請 → 動画内・概要欄で告知 |

## 6. グッズ・スタンプの計画

- [ ] LINEスタンプ第1弾（16個）：日常あいさつ＋ことわざスタンプ → `stamps/stamps.yaml`
- [ ] LINEスタンプ第2弾：人気回のことばを使ったスタンプ
- [ ] ステッカー・アクリルスタンド（`python tools/stamps.py --hires 3000` で高解像度の画像を作る）
- [ ] 手ぬぐい（三毛もよう＋ことばの柄）
