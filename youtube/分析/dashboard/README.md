# ことにゃん制作ダッシュボード

https://claude.ai/artifact/Mgx1nFUx5e2t9qv9ELpG9z

- `episodes.csv` 作った動画の一覧（状態・公開日・最新の再生回数・長さ・曲・カバー画像）
- `views_log.csv` 動画ごとの再生回数の記録
- `channel.csv` チャンネル全体の記録（スクショから）
- `goals.csv` 方針.md の目標
- `index.html` ダッシュボードのページ

数字が増えたら CSV を更新して、ダッシュボードの「Sources」でファイルを差しかえる（または Claude に頼む）。
