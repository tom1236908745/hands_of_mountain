# ep08『挨拶』— ひとこと「おはよう」の朝

- **ことば**：挨拶（禅のことば「一挨一拶」より）
- **基準**：◎ 由来が意外（毎日使うことばが、実は禅のことば）
- **映像**：ep07『和顔愛語』と同じ（`story.py` で ep07 を読みこみ、字幕と吹き出しだけ差し替え）
- **吹き出し**：ことにゃん「おはよう」→ 子ねこ「おはよう！」→ 母ねこ「おはよう」→ くろ「…おはよう」（字幕に重ならないよう横に）

- **解釈の注意**：一挨一拶は、もとは禅僧どうしの問答で相手の力量（悟りの深さ）を試すこと。今の「あいさつ」の意味とは違うので、説明欄でそこを書く
