# ep05『目から鱗』— こわそうな黒ねこの話

- **ことば**：目から鱗が落ちる（新約聖書『使徒言行録』9章18節）
- **核**：思いこみが外れると、ほんとうの姿が見える
- **仕様**：1080×1920、30fps、36秒。セリフなし
- **舞台**：野原と丘。晴れ → 雨 → 虹
- **登場**：ことにゃん、子ねこ、大きな黒ねこ「くろ」（金の目・いつもスン…）

| 時間 | 場面 | 字幕 |
|---|---|---|
| 0–4 | 丘の上にくろ。ことにゃんと子ねこは遊んでいる | 丘の上の、大きな黒ねこ。 |
| 4–8.4 | くろのむすっとした顔に寄る → ふたりはびくびく | いつも むすっとしていて、／こわいねこだと 思っていた。 |
| 8.4–14 | とつぜんの雨。ふたりはずぶぬれでうるうる | とつぜんの 雨。／ふたりとも、ずぶぬれ。 |
| 14–20 | くろが丘を下りてきて、だまって葉っぱの傘をさしかける（照れ） | 黒ねこが だまって、／葉っぱの傘を さしかけてくれた。 |
| 20–25.5 | ことにゃんの顔に寄る。目から**うろこがポロリ**（キラリ）→ にっこり | そのとき、目から なにかが ポロリ。／ほんとうは、やさしいねこだったんだ。 |
| 25.5– | 雨がやんで虹。**目から鱗が落ちる** ― 新約聖書『使徒言行録』9章18節／余韻2行 | 思いこみが ポロリと落ちると、／ほんとうの姿が 見えてくる。 |

- **解釈の注意**：もとはサウロ（パウロ）の目が再び見えるようになった場面。信仰の内容には踏みこまず、現在の慣用的な意味で紹介する
