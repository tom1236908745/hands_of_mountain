# ショートアニメ『タイトル』制作仕様

> 新しいエピソードは `anime/episodes/epNN_<slug>/spec.md` としてこの形で書く。
> ep01_ichigu/spec.md が完成例。Claude Code に「spec.md からアニメにして」と頼むと story.py / score.py / meta.yaml を作る。

## 概要
- **テーマ**：（出典）の「ことば」。本来の意味を一文で。
- **形式**：縦型ショート動画（YouTube ショート、TikTok、Instagram リール向け）
- **仕様**：1080×1920、30fps、XX秒（30〜45秒）、H.264 + AAC ステレオ
- **トーン**：セリフなし。（感情の流れ：例「やさしく、少し切なく、最後は温かい」）。絵本のようなフラットな2Dイラスト調。
- **字幕**：画面上部の約1/3の位置に中央揃え。白文字＋ソフトな影、0.5秒でフェードインしながら少し浮き上がる。

## 登場キャラクター
- **主人公：**（動物・形・色・表情の出し方。光る/変化するなどの“仕掛け”があれば書く）
- **相手役：**
- **（ほか）：**

> 使い回せるキャラ：`anime/cast/` にあるもの（firefly＝ホタル、snail＝カタツムリ親子）。新しいキャラは cast/ に追加する。

## 舞台
- 場所・時間帯・空・背景の層・主要な小道具の配置
- 照明（どこが暗く、何で明るくなるか）

> 使い回せる背景：`anime/scenery.py`（月夜の森・葉・つる草・草むら）

## ストーリーと字幕（タイムライン）
| 時間 | 場面 | 映像 | 字幕 |

| 0–X秒 | 起 | 引きの画。状況と主人公の願い | 1行目／2行目 |
| | 承 | 主人公がうまくいかない | |
| | 転 | 気づき・他者との出会い | |
| | 山場 | 変化が起きる瞬間（光る・咲く・届く…） | |
| | 結 | 結果。ここで「ことば」を明朝体で大きく出す | **ことば**／── 出典 |
| | 余韻 | 引きの画のまま、本来の意味を3行で。最後の1秒で黒にフェード | |
