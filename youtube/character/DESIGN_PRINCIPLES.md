# 親しまれるキャラクターの条件（言語化）

長く愛されるキャラクターや、いまLINEスタンプ・SNSで人気のキャラクターに共通する特徴を、
「見た目」「中身」「いまの時代らしさ」の3つに分けて言葉にしたもの。
**新しいキャラを作るとき・直すときは、このチェックリストで確認する。**

---

## A. 見た目の条件

### 1. シルエットだけで分かる
真っ黒に塗りつぶしても誰だか分かる形。スタンプの小さいサイズやアイコン、グッズのアクリルでも成り立つ。
→ 細かいパーツより「全体の形」に個性を持たせる（おもち形・しずく形など）。

### 2. まるい（角がない）
丸は「安全・やわらかい・さわりたい」と感じさせる形。尖った形は緊張感が出る。
→ 輪郭・耳・手足の先まで角を丸める。

### 3. 赤ちゃんの比率（ベビースキーマ）
大きな頭、低い位置の目、短い手足、ふっくらしたほっぺ。人が本能的に「守りたい」と感じる比率。
→ 頭と体をほぼ一体にして、顔のパーツは**下半分**に寄せる。

### 4. 顔はシンプル（感情を重ねる余白）
目が点・口が小さいほど、見る人が自分の気持ちを重ねられる。描き込んだ顔は感情が一つに決まってしまう。
→ 目は点に近い楕円、鼻は省略、口は小さく。表情は「目の形」と「ほっぺ」で出す。

### 5. 色数をしぼる（3〜4色）
覚えやすく、グッズの印刷代も安い。色が多いと散らかって見える。
→ ベース1色＋アクセント1〜2色＋線の色。

### 6. ひと目で分かる「しるし」が1つある
そのキャラだけの目印（模様・小物）。ほかのキャラと並んでも見分けられる。
→ 三毛のもよう（**左耳が茶・右耳が黒**）＋いつも持っている**小さな「ことば帖」**。

### 7. 表情・ポーズがはっきりしている
スタンプやショート動画では一瞬で気持ちが伝わる必要がある。
→ 「にっこり」「ぴえん」「スン…（無）」など、目の形だけで読める表情を用意する。

## B. 中身の条件

### 8. ちょっとダメなところがある（完璧じゃない）
欠点やドジがあると親しみと応援したい気持ちが生まれる。完璧なキャラは遠い存在になる。
→ 物知りだけど**すぐ眠くなる・ちょっとドジ・食いしん坊**。

### 9. 気持ちに共感できる
「わかる…」と思える小さな感情（めんどう、うれしい、しょんぼり）を、そのまま出す。
→ 教える側ではなく、**一緒に学んで驚く側**にする。

### 10. 行動と口ぐせがぶれない
いつも同じ価値観・同じ口ぐせ。繰り返し見るうちに「この子らしい」が育つ。
→ 口ぐせ「〜なんだって」、古いことばを見つけると「ことば帖」にメモする。

## C. いまの時代らしさ（2020年代のトレンド）

| 前の時代 | いま |
|---|---|
| キラキラの大きな目・描き込み | **点目・ミニマルな顔**（ゆるかわ） |
| はっきりした原色 | **くすみカラー・パステル**（やさしい・目が疲れない） |
| 機械的なきれいな線 | **少しゆらぐ手描き風の線**（あたたかさ・人の気配） |
| 頭と体が分かれた等身 | **おもち・だんご形**（頭と体が一体） |
| 元気・前向きだけ | **弱さ・ゆるさも見せる**（ぴえん、スン…、ねむい） |
| 説明・教える | **一緒に感じる**（共感・癒やし） |

## このチェックリストで作った「ことにゃん」

| 条件 | ことにゃんでの答え |
|---|---|
| 1 シルエット | おもちのような丸いだんご形＋小さな三角耳＋くるんとしたしっぽ |
| 2 まるい | 角のある部分なし（耳の先も丸い） |
| 3 赤ちゃん比率 | 頭と体が一体、顔は下半分、手足は短いぽっちり |
| 4 シンプルな顔 | 点目・ω口・鼻なし、ほっぺ |
| 5 色数 | クリーム白・くすみオレンジ・チャコール（＋線の茶） |
| 6 しるし | 左耳が茶・右耳が黒の三毛／小さな青い「ことば帖」 |
| 7 表情 | 12種（にっこり・ぴえん・スン・鼻ちょうちん など） |
| 8 ダメなところ | すぐ寝る（鼻ちょうちん）、ちょっとドジ |
| 9 共感 | 一緒に驚く・しょんぼりする |
| 10 ぶれない | 口ぐせ「〜なんだって」、ことば帖にメモする |
| いまらしさ | くすみカラー・ゆらぐ手描き線・点目のゆるかわ |

ほかのキャラ（アニメの主人公など）を作るときも、同じ表を埋めてから描く。
