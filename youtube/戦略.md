# 戦略 — 方針を達成するための具体的な進め方

[方針.md](方針.md) の5つの方針を、**何を・いつ・どうやって** に落としたもの。
まずは **段階①（〜12月末：登録者50人・ショート30本）** を確実に達成することに集中する。

---

## 0. 全体像

```
ショート（毎日1本）──見つけてもらう・キャラを好きになってもらう──▶ 登録
      │  関連動画・予告ショート
      ▼
長編（月1本）──ファンが深く楽しむ・総再生時間を積む──▶ 収益化
      │
      ▼
LINEスタンプ・グッズ（登録者が増えてから）
```

## 1. 作る動画の戦略（コンテンツ）

### 1-1. ショートの「勝ちパターン」をそろえる

伸びた ep05 目から鱗・ep08 挨拶・ep04 塞翁が馬 と、伸びなかった ep03 一隅（暗い冒頭）・ep06 雨垂れ（物のアップ）から決めた型。

| 秒 | やること | ねらい（YouTube が見る数字） |
|---|---|---|
| 0〜1 | **明るい画面で、キャラの顔アップ＋冒頭タイトル（ことばだけ大きく）** | スワイプされない |
| 1〜4 | **1行目の字幕は問いかけ**（「この黒ねこ、こわい？」） | 見続ける理由をつくる |
| 4〜20 | **キャラ同士の関係で話を進める**（ことにゃん×くろ／子ねこ） | 感情が動く＝反応 |
| 20〜25 | **意外なオチ・やさしい結末** | 満足 |
| 25〜30 | **ことば（明朝体）＋本来の意味を2行** | 「へえ」＝共有・保存 |
| 最後1秒 | **最初のコマにつながる絵で終わる** | くり返し再生（ループ） |

- **長さは 25〜30秒** を基本に（今は35〜38秒。少しずつ短くして比べる）
- **余韻は 2〜3秒** あれば十分（長いとスワイプされる）
- 字幕は **1画面1行・15字前後**

### 1-2. シリーズを3本柱にする

| シリーズ | 中身 | タイトルの頭 | 割合 |
|---|---|---|---|
| **くろシリーズ** | こわそうな黒ねこ くろ と ことにゃんの関係が少しずつ近づく。毎回 くろの新しい一面 | 「くろの〇〇」 | 4割 |
| **ほんとうは…シリーズ** | 「〇〇って、本当は〜だった」。誤解・意外な語源 | 「〇〇って、本当は…」 | 4割 |
| **ことにゃん日記** | ことにゃん中心のゆるい回（ドジ・ねむい） | 「ことにゃん、〇〇する」 | 2割 |

- 1本ずつ「〇〇シリーズ」の **再生リスト** に入れる（チャンネルページで続けて見てもらえる）
- くろシリーズは **前の回の出来事にふれる**（「このあいだの傘のお礼…」）→ 続けて見たくなる

### 1-3. 題材の選び方（構成メモ「2. ことばの選び方」＋α）

1. **聞いたことはある × 意味はあやふや** であること（必須）
2. **くろ か 子ねこ との関係で描ける** こと（必須）
3. **一言で「えっ」となる**（「我慢って、もとは悪い意味」）
4. 1週間の7本で **仏教・聖書・故事** が偏らないこと

### 1-4. 長編（月1本）

- 題材は **ショートで伸びたことば** の「元のお話」（例：塞翁が馬の元の故事・目から鱗のサウロの話）
  → ショートで興味を持った人が深掘りに来る
- 長さは **3〜5分**、チャプター付き
- 必ず **予告ショート** を1本作る（長編のいちばんいい場面30秒＋「つづきは長編で」）

## 2. 投稿の戦略（運用）

### 2-1. 投稿のリズム

| 曜日 | ショート | 長編 |
|---|---|---|
| 毎日 | 夜 **20:30** に1本 | — |
| 月末の週末 | （予告ショート） | 長編1本 |

- **作りおき7本** を常に持っておく（毎週末に次の週の7本をまとめて作る）
- 同じ ことば・同じ映像の動画は **1週間以上あける**

### 2-2. 投稿するたびに やること（チェックリスト）

- [ ] タイトル：前半に「えっ」となる一文、後ろにハッシュタグ（#猫 必須）
- [ ] 説明：ひとこと＋ハッシュタグ
- [ ] **関連動画**：長編（今は『ありがとう』）を設定
- [ ] **再生リスト**：シリーズのリストに追加
- [ ] **固定コメント**：ことば帖メモ＋**答えやすい問いかけ**（下の型）
- [ ] 視聴者：子ども向けではない
- [ ] 投稿後1時間以内に、来たコメントへ返信（ことにゃんの口調で）

**固定コメントの型**
```
🐾ことにゃんの ことば帖メモ
「〇〇」はもともと（出典）のことば。（本来の意味を1〜2行）
みんなは知ってた？ ①知ってた ②知らなかった　コメントで教えてにゃ
```

### 2-3. よそへも出す（同じ動画を使い回す）

| 場所 | ねらい | 手間 |
|---|---|---|
| **TikTok** | 若い層・猫好き。おすすめに乗りやすい | 同じ動画をそのまま投稿 |
| **Instagram リール** | 癒し・ほっこり層 | 同じ |
| **X（旧Twitter）** | 「ことばの豆知識」として画像＋動画 | 冒頭のコマ＋ことば帖メモ |

- どれも **プロフィールに YouTube チャンネルのリンク**
- まずは TikTok から（ショートと同じ縦動画をそのまま出せる）

## 3. 登録してもらう戦略（いまの最大の課題）

| 手 | 内容 | 作るもの（こちらで用意） |
|---|---|---|
| **最後に一言** | 余韻のあと 1秒だけ「🐾 ことば、もっと集めてるよ」＋ことにゃんが手をふる | 動画の最後に自動で入るようにする |
| **キャラの名前を覚えてもらう** | 毎回の冒頭タイトルの下に小さく「ことにゃん」 | 冒頭タイトルに追加 |
| **続きものにする** | くろシリーズで「前回」「次回」をつくる | 構成に組みこむ |
| **チャンネルの入口を整える** | チャンネルページのおすすめ（トレーラー）に いちばん伸びたショート、再生リストを並べる | （設定はご自身で） |
| **コメントに必ず返信** | 返信があるとまたコメントしてくれる → 反応が増える | 返信文の案を出す |

## 4. 長編を見てもらう戦略

1. **予告ショート**（長編の見せ場30秒・縦）を毎回作る → 関連動画に長編
2. 伸びたショートすべてに **関連動画で長編** を設定
3. 長編の最後の画面（終了画面）に **次に見てほしいショート／長編** を置く
4. 長編は **登録者が 100人をこえるまでは月1本まで**（作る手間をショートに回す）

## 5. 数字を見て直す（ためす計画）

**1回に1つだけ変えて、3〜4本の平均で比べる。**

| 週 | ためすこと | 比べる数字 | 判断 |
|---|---|---|---|
| 12/1〜 | **長さ**：30秒前後 vs これまで（35〜38秒） | 平均再生率・視聴を続けた割合 | 高いほうを標準に |
| 12/8〜 | **冒頭**：ことばだけの冒頭タイトル vs 問いかけ文の冒頭タイトル | 視聴を続けた割合 | 高いほう |
| 12/15〜 | **投稿時間**：20:30 vs 7:30 | 投稿24時間の再生回数 | 多いほう |
| 12/22〜 | **シリーズ**：くろシリーズ vs ほんとうは…シリーズ | 高評価率・登録の増え方 | 多いほうを増やす |

### こうなったら、こう直す（判断ルール）

| 数字 | 原因の見立て | 直すこと |
|---|---|---|
| 視聴を続けた割合が **60%未満** | 最初の1秒が弱い | 冒頭の絵（顔アップ・明るさ）と冒頭タイトル |
| 平均再生率が **70%未満** | 途中がだれる | 中盤を短く。維持率グラフの下がる秒を削る |
| 再生は多いのに高評価率 **1%未満** | 感情が動いていない | オチ・キャラの関係を強く |
| 再生が **300回未満** で止まる | 最初のテストで落ちた | 題材（知名度）と冒頭を見直す |
| 長編のクリック率 **2%未満** | サムネ・タイトル | 顔アップ＋短い問いかけに |

## 8. やらないこと

- 再生数のために **宗教をからかう・こわがらせる** 表現
- **事実と違う** 語源・出典（諸説は諸説と書く）
- 流行の音源だけに頼る（このチャンネルの曲集で統一する）
- 毎日出すために **質を落とす**（作りおきで回す）
