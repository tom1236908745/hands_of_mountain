# ことにゃん エピソード制作

作業ディレクトリは `youtube/`。すべてのコマンドはそこで実行する。

## 手順

1. **設定を読む**: `youtube/構成メモ.md`（動画の型・ネタ帳）、`youtube/character/PROFILE.md`（口調・ルール）と、既存の `youtube/episodes/001〜` を1本読んで文体をそろえる。
2. **ネタ決め**: ユーザーがテーマを指定していなければ、`構成メモ.md` のネタ帳（状態「案」）から、カテゴリ（buddhism / christian / kotowaza / other）が偏らないように3つ出して選んでもらう。
3. **ファクトチェック**: 出典（経典名・聖書の書名と章節・古典の書名と篇名）、原文、意味、由来の話を確認する。Web検索が使えるなら必ず裏を取る。確信が持てない点は台本で断定せず「〜と言われているよ」にし、ユーザーへの報告で明示する。
4. **台本を作る**: `python tools/new_episode.py <slug>` でファイルを作り、`_template.yaml` の構成で埋める。
   - 構成は `構成メモ.md` の「1本の動画の型」に従う: title →（quote：原文）→ talk：意味 → talk：由来・物語 → talk：誤解 or 現代の使い方 → ending
   - 全体 20〜30 行（1〜2分）。1行は40字以内。各シーンは3行前後（チャプターが10秒以上になるように）
   - 難読語・固有名詞は `say:` にひらがなで読みを入れる（VOICEVOXの読み間違い対策）
   - 表情は内容に合わせて変える（PROFILE.md の表）。ending の1行目は `satori`、最後は `happy` の締め台詞
   - `thumbnail.catch` は 2〜3行・各6〜8字の「気になる」問いかけ
   - `references` に確認した資料を書く
5. **確認**: `python tools/render.py episodes/<file>.yaml --preview` を実行し、`output/<file>/preview_landscape/` の画像を見て、文字のはみ出し・改行の不自然さを直す。
6. **書き出し**: `python tools/render.py episodes/<file>.yaml --format both`
7. **構成メモを更新**: ネタ帳の該当行を「台」にしてファイル名を書く（新しいネタなら行を追加）。
8. **報告**: 出力先、動画の長さ、ファクトチェックで不確かだった点、`metadata.txt` のタイトル案を伝える。台本ファイルはコミットする（`output/` はコミットしない）。
