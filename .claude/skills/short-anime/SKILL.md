# ショートアニメ制作

作業ディレクトリは `youtube/`。仕組みの説明は `youtube/anime/README.md`、完成例は `youtube/anime/episodes/ep01_ichigu/`。

## 手順

1. **仕様を決める**
   - ユーザーが仕様書を渡したら、それを `anime/episodes/epNN_<slug>/spec.md` に**そのまま**保存する。
   - 題材は `youtube/構成メモ.md` の「2. ことばの選び方」に合うもの（**聞いたことはある × 意味はあやふや**、誤解されがち・由来が意外なら なお良い）を選ぶ。合わない題材を頼まれたら、そのことを伝えて近い候補も出す。
   - テーマだけのときは `anime/SPEC_TEMPLATE.md` の形で spec.md を書き、ユーザーに確認してもらってから実装する。
   - 題材の出典・原文・諸説を確認する（Web検索が使えるなら裏を取る）。「解釈上の注意」を必ず書く。
2. **実装**（ep01 をコピーして書き換えるのが早い）
   - `story.py`: `FPS`, `SIZE`, `DURATION`, `CAPTIONS`, `render(t)` を定義する。
     - カメラは `Track` のキーフレーム、キャラの動きは `seg()`/`pulse()` で時刻ごとに決める。
     - spec の表の時刻と、字幕・カメラ・演技の時刻をそろえる。
     - キャラは `anime/cast/`、背景は `anime/scenery.py` を再利用する。新しいキャラは cast/ に追加する（ローカル座標・表情パラメータ方式）。
     - 新しいキャラを作るときは、先に `youtube/character/DESIGN_PRINCIPLES.md` の表（シルエット・まるさ・赤ちゃん比率・シンプルな顔・色数・しるし・表情・ダメなところ・共感・ぶれなさ・いまらしさ）を spec.md に埋めてから描く。
   - **曲は曲集から選ぶ**：`meta.yaml` に `music:`（sanpo / wakuwaku / yuugure / wafuu / waltz、音色はマリンバ）。選び方は `youtube/構成メモ.md` の「音楽」の表。となりの回と同じ曲は避ける。
   - `score.py`: `build()` が `audio.Mix` を返す。**効果音・環境音**（雨・小鳥・風・ころぶ音・ぽん など）を spec の時刻に合わせて書く（`music:` があると、score.py の中のメロディ・和音は自動で鳴らなくなる）。
   - 曲だけ変えたいときは `python anime/make.py <ep> --remux`（映像は作り直さず音だけ入れ替え）。
   - `meta.yaml`: 投稿タイトル・説明文・出典・ハッシュタグ・`cover_time`。
3. **確認**（ここを省略しない）
   - `python anime/make.py <ep> --stills 1,5,9,...` で場面ごとの静止画を出し、画像を見て直す：
     キャラが小さすぎ/切れていないか・字幕が読めるか・暗すぎ/白飛びしていないか・spec どおりの演技か。
   - 気になる区間は `--range 開始,終了` で動きを確認する。
   - 「フォントにない文字」の警告が出たら字幕の文字を置き換える。
4. **書き出し**: `python anime/make.py <ep>` → `output/anime/<ep>/` に video.mp4・cover.png・post.txt。
   - 書き出した動画から `ffmpeg -vf "select='not(mod(n\,45))',scale=216:384,tile=9x3"` で一覧画像を作り、通しで確認する。
5. **記録**: `youtube/構成メモ.md` のネタ帳を更新し、spec.md・story.py・score.py・meta.yaml をコミットする（output/ はコミットしない）。
6. **報告**: 出力先、spec から変えた点、音は聞いて確認できていないこと（数値でのチェックのみ）を伝える。

## 守ること
- 宗教・信仰をからかわない。教義の優劣を語らない。出典を明記し、諸説あるものは断定しない。
- 既存のアニメ作品のキャラクター・絵柄・音楽をまねない（オリジナルのキャラ・自作の音楽を使う）。
